# Testimonials

Drop student testimonial proof in this folder: screenshots of wins, Discord or DM messages, payout and
funded-account certificates, broker P&L screenshots, short video clips.

## How to upload

1. Open this folder on GitHub (`assets/jean-ivan/testimonials`).
2. Click **Add file → Upload files** and drag the files in.
3. Click **Commit changes**.

## What works best

- **Images:** `.jpg`, `.png` or `.webp`. Screenshots straight from the phone are fine.
- **Videos:** `.mp4`, ideally under 10 MB each so the page stays fast (GitHub's upload limit is 25 MB per file).
- **Names:** lowercase with dashes, e.g. `marcus-first-payout.png` or `sarah-funded-100k.jpg`.
  Spaces and capitals work, but simple names are easier to put on the page.

Only use real testimonials you have the person's OK to share. Blur out account numbers, emails and
anything else private before uploading.

New uploads don't appear on the pages by themselves: each one is compressed into `assets/jean-ivan/proof/`
and added to the `PROOF` list in `index.html`. Keep the originals here.
